# Add CSI authentication to an interactive Quarto document

Call this once inside the server function in `server.R` for a Quarto
HTML document or dashboard that uses `server: shiny` and the `csiapps`
Quarto extension. It reuses
[`server_wrapper()`](https://csiontario.github.io/csiapps-r/reference/server_wrapper.md)
for CSI OAuth and sends the protected report body to the browser only
after the session is signed in. Sandbox mode reveals the document
locally without contacting CSI authentication.

## Usage

``` r
quarto_setup(
  protected_body = ".csiapps-protected-body.html",
  config_file = ".csiapps-quarto.json",
  sandbox = is_sandbox_mode()
)
```

## Arguments

- protected_body:

  Path to the private body file generated by the Quarto extension. The
  default is correct for a standalone document.

- config_file:

  Path to the private runtime configuration generated by the extension.
  When present, its institute is applied before OAuth starts.

- sandbox:

  Whether to use the existing csiapps sandbox authentication behavior.
  Defaults to
  [`is_sandbox_mode()`](https://csiontario.github.io/csiapps-r/reference/is_sandbox_mode.md).

## Value

Invisibly returns `NULL`. The function registers Shiny observers for the
active session.
